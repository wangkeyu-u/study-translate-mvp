# 留学生课堂翻译助手 MVP

一个第一阶段原型：打开后是 App 式三栏导航，包含首页、API 和我的。首页左侧上传课件并提交给 AI 生成课件大纲和术语表，右侧点击翻译即可开始实时语音翻译；如果课件已经提交，翻译会自动参考课件上下文。用户需要在 API 页面填写自己的 OpenAI 兼容 API Key。

## 运行

```bash
node server.js
```

然后打开：

```text
http://localhost:4173
```

## 第一阶段功能

- 底部导航：首页、API、我的
- 首页左侧：上传或粘贴课件内容，提交后 AI 自动提取课件大纲、专业术语表、易误译词
- 首页右侧：点击翻译按钮开启麦克风，实时识别课堂语音并自动翻译
- 未提交课件时使用普通实时语音翻译
- 提交课件后，实时翻译自动结合课件大纲和术语表优化专业词
- 首页底部：点击生成记忆树表示本节课结束，AI 会生成记忆树并弹出命名窗口
- 记忆树由 AI 根据课件大纲、实时转写和整节课译文生成，并会排除课堂玩笑、闲聊、点名、设备调试等非知识内容
- 实时译文会持续追加并自动滚动到最下方，适合较长课堂持续查看
- 我的页面：保存命名后的记忆树，支持展开/收起、修改节点名称、添加根分支和子分支
- API 页面：填写用户自己的 API Key、模型和 OpenAI 兼容服务地址
- API 页面：内置 GPT-5.2、GPT-5.1、GPT-5、GPT-5 mini/nano、GPT-4.1、GPT-4o 等模型预设，并支持自定义模型名
- 深色潮流界面和本地抽象背景图片，不依赖外网图片资源
- 全站常驻学术 AI Agent，只回答学术、课程、翻译和学习相关问题
- 当前课程状态会保存在本地浏览器，并支持导出/导入 JSON 备份

## 语音识别

实时语音识别使用浏览器 Web Speech API。建议使用 Chrome 或 Edge，并允许网页访问麦克风。

## 文件支持

- `txt` / `md` / `csv` / `json`：完整读取文本
- `pdf`：轻量提取 PDF 文本，复杂扫描版 PDF 可能需要手动粘贴文字
- `pptx` / `docx`：轻量读取 Office XML 文本，复杂格式可能提取不完整

## API 设置

默认使用 OpenAI 兼容接口：

```text
https://api.openai.com/v1
```

模型默认：

```text
gpt-4.1-mini
```

也可以填入其他兼容 `/chat/completions` 的服务地址和模型名。
